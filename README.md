# Premium Interactive Portfolio - DINESH H

A modern, high-performance personal portfolio website for **DINESH H**, Software Developer and Machine Learning Engineer. Built with React 19, TypeScript, Tailwind CSS, Express, and modern visual design principles.

## Features

- **Futuristic Aesthetic**: Deep obsidian background with electric cyan, violet, and indigo accents, interactive particle constellation canvas, and refined glassmorphic surfaces.
- **Hero Showcase**: Dynamic animated typewriter text, quick KPI strip, and instant project/contact jump links.
- **Interactive Skills Explorer**: Filterable by domain (Programming, Frontend, Backend & Databases, AI & ML, Embedded Systems, Tools) with real-time search. Avoids arbitrary percentages in favor of practical engineering capabilities.
- **Featured Projects**:
  1. *AI-Enabled Smart Vehicle Safety System*: Driver-state monitoring, EAR computer vision, and accident prevention pipeline.
  2. *Agricultural Machinery Rental Platform*: Multi-tenant fleet management, equipment booking, and mapping web application.
  3. *Vehicle Accident Alert System*: Embedded sensor fusion with ESP32/MPU6050 and automated emergency GSM dispatch.
  4. *Exercise Classification Using Machine Learning*: YOLOv8 pose estimation tracking 17 skeletal keypoints for form evaluation.
- **Interactive Live Simulators**: Interactive sandbox embedded within each project modal (test drowsiness detection, machinery rental rate estimator, G-force impact qualification, and squat form evaluation).
- **Milestones & Education**: Chronological timeline covering embedded IoT internships, software projects, engineering education, and hackathons.
- **Achievements & Certifications**: Credentials with instant verification records.
- **Functional Contact Dispatch**: Full-stack `/api/contact` backend integration with client-side validation, receipt tracking, and direct email links.
- **Curriculum Vitae Viewer & PDF Generator**: Printable, formatted resume view with instant print/PDF capability.
- **Dual Theme Support**: Dark mode by default with light mode toggle.

## Tech Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide React
- **Backend**: Node.js, Express (REST API with message handling)
- **Testing**: Built-in `node:test` runner with strict assertions (`npx --yes tsx --test`)

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
npm install
```

### Development

Start the full-stack dev server on port 3000:

```bash
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Running Unit Tests

Run the logic test suite:

```bash
npm run test # or: npx --yes tsx --test src/utils/portfolio.test.ts
```

### Production Build

```bash
npm run build
npm start
```

### Deploying to Vercel

This repository is pre-configured for instant deployment on Vercel:

1. Push this repository to GitHub (`github.com/dinesh19-04/...`).
2. Import the project into your Vercel Dashboard.
3. Framework Preset: **Vite**
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Click **Deploy**.
